# cloudwallker

为开发者与研究者制作实用工具：本地使用，结果可检查，源码可复用。



[English](README.md) · 中文

## 从这里开始

下面是按用途整理的项目入口。各仓库都提供示例和上手说明。

### 开发工具

- **[meaning-lock](https://github.com/cloudwallker/meaning-lock)** — 接受改写前，逐项复核数字、日期、限定词、链接与代码的变化。检查在浏览器本地运行，从源码安装。
- **[release-compare](https://github.com/cloudwallker/release-compare)** — 将前后截图制作成对比 GIF，用于 README 或发布说明。在浏览器中预览和导出。
- **[CallTrace](https://github.com/cloudwallker/CallTrace)** — 静态分析函数调用，生成带源码位置、控制流与未解析目标的 Mermaid 时序图。
- **[toolpayload](https://github.com/cloudwallker/toolpayload)** — 找出让已保存 MCP 结果变大的字段，对比基线，在 CI 中检查大小预算。提供离线 HTML 报告。

更多：[pgscope-mcp](https://github.com/cloudwallker/pgscope-mcp)，只读检查 PostgreSQL · [packlens](https://github.com/cloudwallker/packlens)，解释 npm 入包原因并试改虚拟规则。

Agent 工作流技能：[project-skill-builder-skill](https://github.com/cloudwallker/project-skill-builder-skill)，生成项目专用技能 · [Reuse-Scout-skill](https://github.com/cloudwallker/Reuse-Scout-skill)，开展工程研究 · [github-publish-skill](https://github.com/cloudwallker/github-publish-skill)，检查并发布配有双语说明的项目。

### 科研与写作

- **[paper-figure-workflow-skill](https://github.com/cloudwallker/paper-figure-workflow-skill)** — 规划并制作整篇论文的主图与补充图，关联证据和图注，交付可重建的源文件以便返修。
- **[resume-workbench-skill](https://github.com/cloudwallker/resume-workbench-skill)** — 根据目标岗位整理已确认的经历，制作可编辑 Word 简历及其导出的 PDF，也可从最新 Word 继续修改。

更多：[TableProof](https://github.com/cloudwallker/TableProof)，对照原始单元格检查 Excel 转 Markdown 的保真情况。

[term-history-skill](https://github.com/cloudwallker/term-history-skill) 用可核验的证据调查词条出处、传播与趋势。

### 学习与生活

- **[codex-student-tutor-skill](https://github.com/cloudwallker/codex-student-tutor-skill)** — 基于教材开展小学、初中与高中学习辅导的 Skill。
- **[video-recipe-extractor-skill](https://github.com/cloudwallker/video-recipe-extractor-skill)** — 从做菜视频整理菜谱长图，配一张真实视频画面和文字步骤，沿用来源中的用量。

## 试用一个项目
