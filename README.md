# cloudwallker

I build practical tools for developers and researchers: local workflows, inspectable results, and reusable source.


English · [中文](README_ZH.md)

## Start here

Project entry points, organized by the task you want to do. Each repository has examples and instructions for getting started.

### Developer tools

- **[meaning-lock](https://github.com/cloudwallker/meaning-lock)** — Review changes to numbers, dates, qualifiers, links, and code before accepting a rewrite. Checks run locally in your browser; install from source.
- **[release-compare](https://github.com/cloudwallker/release-compare)** — Turn before-and-after screenshots into comparison GIFs for READMEs and release notes. Preview and export in your browser.
- **[CallTrace](https://github.com/cloudwallker/CallTrace)** — Follow function calls through static analysis and generate Mermaid sequence diagrams with source locations, control flow, and unresolved targets.
- **[toolpayload](https://github.com/cloudwallker/toolpayload)** — Find the fields that make saved MCP results large, compare a baseline, and enforce size budgets in CI. Includes an offline HTML report.

Also: [pgscope-mcp](https://github.com/cloudwallker/pgscope-mcp) for read-only PostgreSQL inspection · [packlens](https://github.com/cloudwallker/packlens) for explaining npm package contents and testing virtual rule changes.

Agent workflow skills: [project-skill-builder-skill](https://github.com/cloudwallker/project-skill-builder-skill) for project-specific skills · [Reuse-Scout-skill](https://github.com/cloudwallker/Reuse-Scout-skill) for engineering research · [github-publish-skill](https://github.com/cloudwallker/github-publish-skill) for checked, bilingual project publishing.

### Research & writing

- **[paper-figure-workflow-skill](https://github.com/cloudwallker/paper-figure-workflow-skill)** — Plan and produce a paper's main and supplementary figures, keep evidence and captions connected, and deliver sources that can be rebuilt for revisions.
- **[resume-workbench-skill](https://github.com/cloudwallker/resume-workbench-skill)** — Shape confirmed experience for a target role and create an editable Word resume with its PDF export. Continue from your latest Word file.

Also: [TableProof](https://github.com/cloudwallker/TableProof) for checking Excel-to-Markdown fidelity against source cells.

[term-history-skill](https://github.com/cloudwallker/term-history-skill) traces verifiable term origins, spread, and trends.

### Learning & everyday life

- **[codex-student-tutor-skill](https://github.com/cloudwallker/codex-student-tutor-skill)** — Textbook-based tutoring skills for primary, junior, and senior school learning.
- **[video-recipe-extractor-skill](https://github.com/cloudwallker/video-recipe-extractor-skill)** — Turn a cooking video into a recipe image with a real video frame and written steps, preserving the quantities given in the source.
